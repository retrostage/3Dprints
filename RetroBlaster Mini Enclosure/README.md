# RetroBlaster Mini Enclosure

There are two files here: the 3MF, and the STL.
The 3MF file is the recommended one if you have a 3D printer that supports multiple colours, as it uses two colours - one for the logo text, and one for the enclosure.
The STL file does not have any text, so is the file you should use if you have a single-colour 3D printer.

They should print fine at standard 0.2mm, 15 or 20% infill settings, and no rafts/supports needed as long as you print upside down with the logo side on the printer bed.
